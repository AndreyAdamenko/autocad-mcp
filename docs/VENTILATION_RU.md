# Вентиляция: AutoCAD 2014 → MCP → Blender → локальный просмотрщик

Проверено на проекте 5800–1.3: AutoCAD `19.1s (LMS Tech)`, Blender 5.2.2 LTS,
Windows. Получена **обзорная** модель вентиляции. Монтажная и аэродинамическая
достоверность не подтверждена.

Результат: `artifacts/ventilation/erdaut_with_ventilation.blend` — исходные 1 121
архитектурных объектов и 451 новый объект вентиляции. Включены П1/В1, В2–В5,
ВЕ1/ВЕ2, этажные трассы, стояки, 28 квадратных и 13 круглых приборов,
пять решёток, 28 гибких подключений и упрощённые корпуса оборудования.
Число mesh-объектов не является числом изделий: оболочки и детали разделены.

## Фактические источники

- ОВ-011/012/013/014 REV.0: планы двух этажей, кровли и схемы.
- ОВ-002 REV.0: общие указания, включая изоляцию 6/40 мм.
- ОВ.СО REV.1: спецификация, в том числе ПВУ 961 × 986(h) × 3378 мм.
- Базовый архитектурный BLEND с сохранёнными исходными COM-пакетами.

Геометрия планов и схем повторяется в ModelSpace разных листов. Сравнение
контрольных привязок сохранено в `evidence/ventilation/common-anchor-comparison.json`.
Основная выборка прочитана из ОВ-011: 1 899 корневых handles, 11 263 записи с
учётом вложенности. Отдельно через MCP дочитана отметка +3.150 без bbox.
Неустановленные библиотечные изделия и архивные варианты исключались по
фактическому расположению. Все пути/хеши лежат в локальном evidence и BLEND.

DWG открывается COM с `ReadOnly=True`. Не применяются Explode, Export,
SendCommand, сохранение исходного файла или промежуточная конвертация.
Можно использовать только побитово проверенную локальную копию исходного DWG.
PNG служит контролю, GLB создаётся из готового проверенного BLEND для браузера.

## Что изменено в MCP

- `build_blender_model`: необязательные `root_handles`, `selection_evidence`,
  `visible_only`. Корень проверяется по OwnerID ModelSpace; ребёнок блока
  напрямую не принимается, чтобы сохранить цепочку преобразований.
- `visible_only=true` явно исключает невидимые варианты динамических блоков.
  По умолчанию прежний полный обход сохранён. Выборка не считается полным DWG.
- Читаются параметры динамических блоков и видимость каждого объекта.
  Фланец или bbox со скрытым вариантом не подменяет физическое сечение.
- makepy-объект `IAcadEntity` переопределяется через фактический интерфейс
  сущности. Это было проверено на вложенных линиях в живом AutoCAD 2014.
- MLeader сохраняет текст и доступные выноски с разреженными индексами.
  Его графика по-прежнему помечается неподдержанной. Для MLine сохраняется
  базовая линия и параметры стиля; полное воспроизведение стиля не заявляется.
- Кэши обхода ограничены: 10 000 метаданных, до 4 096 небольших геометрий
  в пределах 16 МиБ, 128 определений блоков. Крупные сущности не удерживаются
  в геометрическом кэше; блоки свыше 1 024 детей перечисляются последовательно.
- `inspect_drawing_annotations` принимает `scope=all/model/paper`.
- `assemble_ventilation_model` запускает bpy-сборку из сохранённого COM-пакета
  и базового BLEND, проверяя хеши и создавая новый файл.

Новый сборщик имеет профиль **`erdaut_ventilation_overview`**. Имена блоков,
handles отметок, габариты сетки и правила распознавания относятся к этому
зданию. Для другого проекта нужно подготовить другой профиль, сверить оси,
системы и источники уровней. Он не является универсальным проектировщиком ОВ.

## Модули

| Файл | Назначение |
|---|---|
| `autocad_mcp/ventilation.py` | Численные оболочки, переходы, изоляция, замкнутые плановые грани |
| `autocad_mcp/ventilation_project.py` | Привязки и распознавание измеренных участков данного проекта |
| `autocad_mcp/ventilation_details.py` | Фасонные части, приборы, стояки, корпуса и явные допущения |
| `autocad_mcp/ventilation_worker.py` | bpy-сборка с сохранением архитектуры и встроенных источников |
| `autocad_mcp/ventilation_bridge.py` | Запуск Blender из MCP |
| `tools/capture_ventilation_source.py` | Реальный MCP-клиент для захвата выбранной COM-геометрии |
| `tools/assemble_ventilation.py` | Реальный MCP-клиент сборки из захваченных источников |
| `tools/verify_ventilation.py` | Повторное открытие, размеры по COM, сохранность здания, коллизии |
| `tools/render_ventilation_model.py` | Пять контрольных видов сохранённой модели |
| `tools/report_ventilation.py` | Русский отчёт из фактического результата проверки |
| `tools/audit_ventilation_sources.py` | Сравнение защищённой папки и исходных хешей |

## Воспроизведение на сохранённых источниках

Для новых выводов используйте **новые имена файлов**: сборщик отказывается
перезаписывать существующий BLEND. Настройки проекта содержат пути и правила,
а не экспортированную геометрию:

```json
{
  "profile": "erdaut_ventilation_overview",
  "base_model": "C:/path/AutocadMCP/artifacts/erdaut_overall_view.blend",
  "source_blend": "C:/path/AutocadMCP/artifacts/ventilation/ov_visible.blend",
  "supplementary_sources": ["C:/path/AutocadMCP/artifacts/ventilation/ov_levels.blend"],
  "catalogue_path": "C:/path/AutocadMCP/evidence/ventilation/layout-catalogues.json",
  "accepted_overview_assumptions": true,
  "regions": {
    "ground": [365000,430000,-530000,-496000],
    "upper": [430000,500000,-530000,-496000],
    "roof": [500000,565000,-530000,-496000],
    "schemes": [360000,435000,-590000,-535000]
  }
}
```

`accepted_overview_assumptions` допустим только в уже согласованном обзорном
задании. Не включайте его молча при запросе точной монтажной модели.

```powershell
python tools\assemble_ventilation.py --project evidence\ventilation\project.json --output ventilation\new_model.blend --report evidence\ventilation\new_assembly.json
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background artifacts\ventilation\new_model.blend --disable-autoexec --python-exit-code 3 --python tools\verify_ventilation.py
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background artifacts\ventilation\new_model.blend --disable-autoexec --python-exit-code 3 --python tools\render_ventilation_model.py
python tools\report_ventilation.py artifacts\ventilation\new_model.blend
python tools\audit_ventilation_sources.py --verify
```

Чтобы заново читать DWG, сначала проверьте доступность AutoCAD 2014 COM,
read-only статус, единицы и актуальность выборки handles, затем запустите
`tools/capture_ventilation_source.py`. Процесс клиента использует локальный
makepy-кэш; глобальные настройки pywin32 не изменяются.

Встроенный журнал хранит исходные записи, параметры, статусы допущений и
ожидаемые вершины. Верификатор повторно измеряет сохранённые mesh, отдельно
восстанавливает 86 прямых участков по исходному COM-пакету, сверяет исходные
аннотации и сечения и сравнивает все 1 121 архитектурных объектов с базой.

## Пройденные проверки и оставшиеся вопросы

- 1 572 сохранённых объектов проверены; максимальная численная ошибка
  вершин относительно журнала построения 0,001984 мм. Независимая сверка
  прямых участков с COM дала максимум 0,056957 мм при допуске 0,25 мм.
- Архитектурная геометрия сохранена без изменения вершин.
- 363 файла исходной защищённой папки: добавлений, удалений и изменений нет;
  проверены SHA-256 18 исходных DWG ОВ и их локальных копий.
- GLB: 1 572 объекта, 66 436 треугольников; максимальная ошибка экспорта
  0,001759 мм. Исходный BLEND не изменился.
- Обнаружены 39 пар пересекающихся поверхностей: стены 31, плиты 3,
  кровля 2, парапет 1, балки 2. Проходы конструкций в обзорном здании не вырезаны.
- Стояк В5 пересекает две балки модели: требуется согласование ОВ/КЖ.
- 15 концов прямых участков не имеют подтверждённого контакта в пределах 5 мм.
  Их координаты и ближайшие оболочки перечислены в отчёте. Автоматическое
  соединение ближайших объектов может ошибочно объединить разные системы.

Отметка квадратных диффузоров +2.750 от пола, высоты ряда корпусов и зонтов,
форма отдельных переходов, подвес ПВУ и часть высотных сопряжений остаются
допущениями. Высота прямоугольных участков связывается с ближайшей выноской
той же ширины эвристически. Численная проверка такого значения не доказывает
правильность связи выноски с конкретным участком.

`complete=false`, `engineering_coordination_complete=false`,
`full_fidelity=false` сохранены намеренно. Обзорный результат доступен,
инженерно согласованной монтажной модели пока нет. Полный русский отчёт:
`artifacts/ventilation/erdaut_with_ventilation.summary.ru.md`.

## Локальный просмотрщик

Канонический [отдельный репозиторий просмотрщика](https://github.com/AndreyAdamenko/darbaza-5800-1.3-erdaut-model-viewer)
локально расположен в соседней папке `AutocadModelViewer`.
Он содержит фильтр «Вентиляция», кнопку «Только сети», выбор системы,
горизонтальный и вертикальный разрезы, переключатель «Не резать инженерные сети»
и карточку с номинальным сечением/статусом допущений.
Экспорт вентиляции требует успешного отчёта повторного открытия для точного
SHA-256 исходного BLEND. В GLB попадают только разрешённые публичные поля,
без встроенного COM-журнала и путей защищённой папки.

Предыдущие assets сохранены в отдельном репозитории в
`artifacts/assets-before-ventilation-20261015`. Локальный адрес:
`http://127.0.0.1:8765/`. 16.10.2026 выполнено развёртывание через Portainer
на сервере компании с отдельным каталогом модели и проверенным Git polling.
Настройки и результаты проверки находятся в `PORTAINER.md` репозитория просмотрщика.
Копия `viewer/` и её утилиты экспорта/упаковки/сервера в MCP не отслеживаются.
