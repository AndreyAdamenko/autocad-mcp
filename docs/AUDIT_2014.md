# Аудит AutoCAD 2014 → Blender

Дата: 2026-10-15. Исходный репозиторий: https://github.com/Slacker-LLC/autocad-mcp,
commit `2723b4fae13ac7bc91274fcd502528b92da7a6a5`.

## Исходное состояние (до изменений)

* `acad_core.py:60`: подключение только через ProgID 25.1/25/без версии.
  Требуется 19.1 и проверка фактического `Application.Version`; в системе также
  зарегистрированы библиотеки DWG TrueView 2021/2025.
* `tools/acax_probe.py:59`: выбирается самая новая acax*.tlb. Это не доказывает
  наличие методов в AutoCAD 2014. Установлена `acax19enu.tlb`.
* `acad_core.py:104,529`: DXF SaveAsType=65 (2018) несовместим с 2014.
  В рабочем процессе чтения сохранение/экспорт должны быть вообще запрещены.
* `open_drawing`: `Documents.Open(path, False)` открывает для изменения.
* 29 исходных инструментов включают добавление, удаление и сохранение объектов.
  Нужен режим только чтения по умолчанию, в том числе защита прямого вызова
  скрытого инструмента. Исходные функции сохраняются для явного режима legacy.
* `query_entities`: только handle/type/layer/color/linetype; обход ограничен и
  возобновления нет. Координаты, bulge, block transforms и вложения отсутствуют.
* Пересчёт INSUNITS уже есть. Для нового потока неопределённые единицы нельзя
  выдавать за миллиметры. Нужны явные единицы и подтверждённый override.
* COM STA и последовательный доступ уже реализованы; сохранены.
* Blender, интерпретация, сравнение и контрольные рендеры отсутствуют.
* Исходные тесты используют поддельный COM; не подтверждают работу AutoCAD.

## Среда до теста подключения

Windows; `C:\Python312\python.exe` 3.12.3 x64, pywin32 и mcp 1.26.0 доступны.
AutoCAD 2014 установлен. Blender 5.2 установлен. В изолированном процессе
инвентаризации acad первоначально не был виден; последующая проверка вне
песочницы обнаружила работающий AutoCAD и установила COM-соединение.
Наличие установки/реестра не считается
успешным подключением. Фактические результаты сохраняются в `evidence/`.

## Граница возможностей

Полная геометрия произвольного DWG через один ActiveX API не гарантируется.
Прокси AEC, ACIS 3DSolid/Body/Surface и некоторые mesh/topology данные могут
не предоставлять read-only доступ к граням. Запрещено подменять точное тело
его bounding box. Такие объекты должны попадать в список неподдержанных с
измерениями и причиной; проверка полноты должна завершаться неуспехом.
Устранение этого ограничения может потребовать расширения требований
(например, собственного ObjectARX модуля), что не входит в COM-only путь.

Высоты и назначение элементов по одним линиям неоднозначны. Классификация
должна возвращать гипотезы и основания; объёмы создаются только при наличии
полного явного правила и параметров с происхождением.
