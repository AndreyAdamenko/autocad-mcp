# Подключение и реально доступные инструменты

## Поиск установки

- MCP: `autocad_2014`, локальный stdio-процесс, запускаемый клиентом.
- Репозиторий: определи по `cwd` или аргументу `server.py` в настройках MCP.
- Python: исполняемый файл из `command` конфигурации; entrypoint: `server.py`.
  При установке из исходников обычно используется `.venv/Scripts/python.exe`.
- Конфигурация: пользовательский `config.toml` в каталоге Codex
  (`CODEX_HOME`, по умолчанию `~/.codex`) или проектный `.codex/config.toml`,
  секция `mcp_servers.autocad_2014`. Пример `config/codex-mcp.toml`
  в репозитории содержит пути исходного компьютера: их необходимо адаптировать.
- AutoCAD ProgID: `AutoCAD.Application.19.1`; ожидаемая версия: `19.1`.
- Библиотека типов: `C:/Program Files/Common Files/Autodesk Shared/acax19enu.tlb`.
- Каталог результата задаёт `ACAD_MCP_OUTPUT_ROOT`. Проверяй актуальное значение
  перед записью; не полагайся на имя папки из другого проекта.

AutoCAD должен быть запущен в той же интерактивной Windows-сессии и с теми же
правами, что MCP. Сервер подключается к работающему AutoCAD, сам его не запускает.
Ошибка ROT/MK_E_UNAVAILABLE может означать разные сессии или уровни прав.
Не запускай другой AutoCAD и не переключайся на другой ProgID молча.

Стандартная конфигурация `ACAD_MCP_READ_ONLY=1` скрывает и блокирует инструменты
изменения DWG, включая операции с документами и `zoom_extents`.
Для разрешённой задачи редактирования требуется процесс MCP с
`ACAD_MCP_READ_ONLY=0`. Изменение значения в конфигурации действует после
перезапуска MCP-хоста; одно изменение файла ещё не доказывает смену режима.
Навык сам не меняет настройку и не даёт разрешение редактировать документы.

Если MCP недоступен, сначала проверь конфигурацию и запуск stdio, затем COM.
Не запускай бесконтрольно второй сервер в терминале: клиент должен владеть
его stdin/stdout. Логи не должны смешиваться с протоколом stdout.

## Карта инструментов

| Задача | Инструменты |
| --- | --- |
| Проверить COM и документы | `diagnose_compatibility`, `get_active_drawing_info`, `list_open_drawings` |
| Открыть исходник только для чтения | `open_source_drawing` |
| Слои, определения блоков, листы | `list_layers`, `list_blocks`, `list_layouts` |
| Быстрая выборка объектов | `query_entities` |
| Аннотации и таблицы | `inspect_drawing_annotations` |
| Полная пакетная геометрия | `start_geometry_scan`, `read_geometry_batch`, `close_geometry_scan` |
| Создать/открыть редактируемый документ | `create_new_drawing`, `open_drawing` |
| Сохранить DWG | `save_drawing_as`, `save_active_drawing` |
| Создать геометрию/надписи | `draw_line`, `draw_polyline`, `draw_circle`, `draw_arc`, `draw_ellipse`, `draw_point`, `draw_text` |
| Вставить существующий блок, создать размер | `insert_block`, `add_linear_dimension` |
| Изменить объекты | `move_entity`, `copy_entity`, `erase_entity`, `set_entity_layer` |
| Управлять слоями | `create_layer`, `set_layer_properties` |
| Визуальная проверка | `capture_screenshot`, `zoom_extents` |

Актуальный список MCP и схемы — источник истины. Например, текущие инструменты
не предоставляют общего редактирования существующего текста, произвольных
свойств блоков, штриховок или ACIS-граней. Не подменяй такую операцию удалением
и пересозданием объекта без учёта связей и согласованного результата.
При необходимости доработки MCP сначала исследуй COM API и проверь новую
операцию на тестовом документе. Не обходи ограничения через SendCommand/LISP.

## Единицы и пространства

Поля инструментов с суффиксом `_mm` принимают миллиметры; углы `_deg` — градусы.
COM-данные могут быть в единицах чертежа, их масштаб задаёт manifest.
Не применяй масштаб второй раз. Подтверждай неизвестные единицы.

`space="paper"` в старых инструментах означает активный лист. `list_layouts`
не переключает листы; не обещай правку выбранного неактивного листа без
подтверждённого механизма выбора. Инструменты редактирования используют
активный документ, а не путь последнего прочитанного скана.

Для диагностики API можно читать установленную библиотеку типов:
`python tools/check_extraction_api.py`. Это не живая проверка всех COM-вызовов.
`python -m unittest discover -s tests` проверяет код, а не фактические чертежи.
