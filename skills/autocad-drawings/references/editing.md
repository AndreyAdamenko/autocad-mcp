# Редактирование DWG

## Область изменения

Определи целевой документ, объекты/handles, требуемое изменение и куда сохранить
результат. Явный запрос пользователя на конкретную правку является разрешением
этой правки; не добавляй повторное подтверждение каждой обычной операции.
При неоднозначном документе или масштабе останови зависимые изменения и уточни
только недостающую информацию.

По умолчанию сохраняй исходник и создавай новую рабочую DWG-копию. Если пользователь
явно выбрал редактирование исходного файла, соблюдай этот выбор и существующие
ограничения доступа. Для ранее объявленной защищённой папки не считай общий запрос
«отредактируй» отменой её защиты; работай с копией в разрешённом каталоге.

Создание/установка этого навыка не включает запись в AutoCAD.
Когда редактирование разрешено, но MCP read-only, подготовь понятный набор правок,
проверь цель и включи режим записи только в рамках имеющейся авторизации и
доступного механизма конфигурации. При необходимости запроса разрешения объясни
конкретную причину. Не обходи отказ через другой COM-процесс или shell.
После перезапуска убедись, что нужные инструменты действительно появились.
Если временно менял режим для этой задачи, верни исходную настройку после проверки.

## До изменения

1. Проверь текущие несохранённые изменения и `ReadOnly` документа.
   Не закрывай и не сохраняй чужой незавершённый документ автоматически.
2. Для копии используй новый путь в `ACAD_MCP_OUTPUT_ROOT`.
   Если нужны несохранённые изменения из памяти, обычное копирование файла
   с диска недостаточно: согласуй нужное состояние и используй подходящий SaveAs.
3. Открой редактируемую копию через `open_drawing`, затем проверь
   `get_active_drawing_info`: полный путь, единицы, статус и нужное пространство.
4. Прочитай исходные свойства целевых объектов, их слои и геометрию.
   Зафиксируй ожидаемую дельту: положение, количество, длины, текст или слой.
   Для удаления перечисли конкретные найденные объекты.

## Выполнение

- Выполняй связанные изменения последовательно; не отправляй параллельные
  мутации в одну AutoCAD-сессию. Пользователь может переключать документы между
  вызовами: проверяй активный путь перед каждой группой правок и после перерыва.
- Адресуй объект handle в проверенном документе, а не экранными координатами.
  Прямое изменение дочернего объекта определения блока может затронуть все
  вставки. Для изменения одного экземпляра выбирай reference или другой
  подтверждённый механизм, не редактируй определение случайно.
- Проверь существование и состояние слоя до создания объекта.
  Не размораживай и не разблокируй посторонние слои без необходимости.
- Для сдвига `move_entity` используй from/to в миллиметрах; `[0,0]` → `[dx,dy]`
  задаёт вектор. `copy_entity` возвращает новый handle; без displacement копия
  создаётся поверх оригинала.
- `draw_polyline` создаёт плоскую LWPolyline: разные Z нельзя молча сплющивать.
  `draw_arc` строит против часовой стрелки; полный круг — `draw_circle`.
  Оси `draw_ellipse` являются полуосями.
- `insert_block` вставляет уже существующее определение с равномерным масштабом.
  Это не импорт блока из другого файла и не универсальная правка dynamic properties.
- `add_linear_dimension` возвращает фактически измеренное `measurement_mm`.
  Не заменяй геометрию переопределённым текстом размера ради совпадения числа.
- После тайм-аута изменяющего вызова сначала проверь фактический результат.
  Не повторяй создание, перенос или удаление вслепую: операция могла завершиться.

## Сохранение и проверка

`save_drawing_as` принимает относительный путь внутри `ACAD_MCP_OUTPUT_ROOT`;
для результата DWG используй расширение `.dwg`. Существующий результат по
умолчанию не перезаписывается. `save_active_drawing` сохраняет текущий документ
на месте, поэтому вызывай его лишь для проверенного разрешённого назначения.

Сверь дельту количества, новые/изменённые handles, координаты, длины, слои и размеры.
При необходимости проверь сохранённый DWG повторным чтением, учитывая текущие
несохранённые документы. Подтверди наличие итогового файла; для задачи с сохранением
исходника проверь его неизменность. Скриншот AutoCAD полезен при визуальной правке,
но окно должно быть открыто и не перекрыто.

Нет гарантии транзакционного отката набора MCP-вызовов. При частичной ошибке
зафиксируй уже выполненное и оставшееся, не утверждай полный успех и не сохраняй
частичный результат поверх оригинала. Стандартный Undo AutoCAD не означает,
что сервер умеет автоматически откатывать изменения.
